# FireFlow AI Idea

FireFlow AI는 화재 대응 흐름을 시민, 소방관, 중앙 통제 역할로 나누어 각 역할에 필요한 정보만 빠르게 제공하는 서비스입니다.

## MVP 목표

- 실제 인증 없이 첫 화면에서 역할을 선택합니다.
- 모든 AI 응답과 공공/지도/건물 정보는 더미 데이터로 처리합니다.
- 시연 가능한 프론트엔드와 백엔드 API 계약을 안정적으로 구성합니다.

## 핵심 가치

- 시민에게는 즉시 실행 가능한 대피 행동 지침을 제공합니다.
- 소방관에게는 신고 텍스트와 건물 특성을 압축한 현장 요약을 제공합니다.
- 중앙 통제에는 여러 신고의 위험도와 출동 상태를 정렬해 보여줍니다.
