# FireFlow AI Idea

## 1. 서비스 한 줄 소개

FireFlow AI는 화재 발생 시 시민, 소방관, 중앙 통제 담당자에게 각자의 역할에 맞는 핵심 정보를 빠르게 제공하는 AI 기반 소방안전 웹서비스 MVP입니다.

---

## 2. 문제 정의

화재 상황에서는 같은 정보라도 역할에 따라 필요한 형태가 다릅니다.

- 시민은 복잡한 분석보다 즉시 실행할 수 있는 대피 행동이 필요합니다.
- 소방관은 여러 신고 내용과 건물 정보를 짧은 시간 안에 파악해야 합니다.
- 중앙 통제 담당자는 다수 신고의 위험도와 출동 상태를 비교해야 합니다.

그러나 신고 내용, 건물 정보, 현장 대응 정보가 서로 분리되어 있으면 필요한 정보를 찾고 판단하는 데 시간이 걸릴 수 있습니다.

---

## 3. 해결 방식

FireFlow AI는 하나의 화재 신고 데이터를 역할별 목적에 맞게 다시 구성합니다.

```text
화재 신고 + 건물 정보
        │
        ▼
역할별 정보 가공
        │
        ├─ 시민: 대피 행동 지침
        ├─ 소방관: 현장 브리핑
        └─ 중앙 통제: 신고 우선순위 및 출동 현황
```

AI는 새로운 사실을 임의 생성하는 역할이 아니라, 입력된 신고와 건물 정보를 역할별로 요약하고 정리하는 보조 도구로 사용합니다.

---

## 4. MVP 목표

- 실제 인증 없이 첫 화면에서 역할을 선택합니다.
- 시민, 소방관, 중앙 통제 화면을 독립적으로 제공합니다.
- 모든 AI 응답과 지도·공공·건물 정보는 더미 데이터로 처리합니다.
- React 프론트엔드와 FastAPI 백엔드 간 API 계약을 안정적으로 구성합니다.
- 외부 API 연동 없이도 전체 서비스 흐름을 시연할 수 있게 합니다.
- 이후 실제 AI, 지도, 공공데이터로 교체할 수 있는 구조를 준비합니다.

---

## 5. 역할별 핵심 가치

### 시민

- 즉시 실행 가능한 대피 행동 지침 제공
- 피해야 할 행동과 주의사항 표시
- 복잡한 정보를 간결한 문장으로 전달

### 소방관

- 신고 텍스트와 건물 특성을 압축한 현장 브리핑 제공
- 인명 관련 정보와 주요 위험 요소 우선 표시
- 현장에서 추가 확인해야 할 항목 정리

### 중앙 통제

- 여러 신고의 위험도와 출동 상태 비교
- 우선 대응이 필요한 신고를 상단에 배치
- 신고별 핵심 정보와 전체 통계를 함께 제공

---

## 6. 대표 시연 시나리오

1. 사용자가 첫 화면에서 역할을 선택합니다.
2. 시민 역할에서는 특정 화재 신고의 대피 행동 지침을 확인합니다.
3. 소방관 역할에서는 동일한 신고의 현장 브리핑을 확인합니다.
4. 중앙 통제 역할에서는 여러 신고를 위험도와 출동 상태 순으로 확인합니다.
5. 하나의 신고 데이터가 역할별로 다르게 표현되는 과정을 시연합니다.

---

## 7. MVP 핵심 기능

- 역할 선택
- 신고 목록 및 상세 조회
- 건물 기본 정보 조회
- 시민용 대피 안내
- 소방관용 현장 브리핑
- 중앙 통제용 통계와 신고 현황
- 위험도 및 출동 상태 표시
- 지도 Placeholder
- API 오류 및 빈 데이터 상태 처리

---

## 8. MVP에서 하지 않는 것

- 실제 119 신고 접수
- 실제 소방 출동 시스템 연동
- AI가 생성한 대피 경로의 안전 보장
- 실시간 위치 추적
- 실제 건물 도면 기반 길찾기
- 실시간 화재 감지 센서 연동
- 실제 사용자 인증과 권한 관리

---

## 9. 향후 확장 방향

### 1단계: 실제 데이터 연동

- 건축물 정보 공공데이터
- 지도 및 좌표 API
- 실제 데이터베이스

### 2단계: AI 고도화

- 신고 음성의 텍스트 변환
- 신고 내용 자동 분류
- 역할별 요약 생성
- 응답 근거 표시

### 3단계: 현장 연동

- 소방관 모바일 화면
- 관제 대시보드 실시간 갱신
- 건물 도면 및 소방시설 정보 연동
- 센서 및 IoT 데이터 연동

---

## 10. 서비스 원칙

- AI는 소방관과 시민의 판단을 대체하지 않습니다.
- 확인된 정보와 추정 정보를 구분합니다.
- 실제 재난 상황에서는 119와 현장 안내를 우선합니다.
- 실제 연동되지 않은 기능은 시연용임을 명확히 표시합니다.
- 역할별로 필요한 정보만 간결하게 제공합니다.
